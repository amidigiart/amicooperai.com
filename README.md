# AmiCooperAI

The smallest human-guided AI brain — designed for every home.

**Live:** [amicooperai.com](https://amicooperai.com)

## What It Is

Cooper is a local-first AI inference engine that runs on consumer hardware (phone, Raspberry Pi, old laptop). No cloud. No GPU. No subscription.

One structural constraint: **a human must guide it.** Cooper does not decide. Cooper does not act autonomously. Cooper waits, processes, returns an honest answer — or says "I don't know."

## Design Principles

1. **Small by Design** — must run on consumer hardware (≤ 3B parameters, CPU-only)
2. **Human-Guided Always** — autonomy = 0, human-initiated only
3. **Local-First, Private-Forever** — zero telemetry, data stays on device
4. **Honest Over Capable** — refuses rather than confabulates (DSEI structural)
5. **For Every Home** — from Brăila to Berlin, every smartphone can run Cooper

## Technical Profile

| Parameter | Target |

| Model size | ≤ 3B parameters (quantised) |
